# Portfolio: Source of Truth

This `docs/` folder is the **single source of truth** for the content and voice of the
Trung (Ethan) Truong portfolio site (`../index.html`).

The site is a single self-contained `index.html` (dark theme, amber + teal, vanilla JS, no build
tooling). The hero is a desktop: folders, a Finder window and notes hold the work. These docs keep copy, positioning
and project details consistent as the site evolves.

## How to use it

1. **Draft here first.** When changing copy or adding work, update the relevant doc below.
2. **Then mirror into `index.html`.** The HTML is the deliverable; these docs drive it.
3. **Keep them in sync.** If the site and a doc disagree, treat this folder as canonical and
   fix the site, unless the change was a deliberate live edit not yet recorded here.
