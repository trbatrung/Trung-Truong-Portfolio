## Design language (tech × film)
- **Palette:** near-black base; **amber `#e6a15b`** (film craft) + **teal `#57cbbb`** (AI/tech) —
  a nod to the cinematic "orange & teal" grade. Amber = interactive/emphasis; teal = technical
  metadata (indices, timecodes, labels).
- **Type:** Fraunces (display serif / film) · Space Grotesk (body) · IBM Plex Mono (metadata / tech).
- **Motifs:** film grain, vignette, live running timecode, crop-mark corners, mono spec-sheet labels.
- Entrance motion is enhancement only (guarded by `prefers-reduced-motion`; `<noscript>` fallback) —
  content is never hidden if JS/animation don't run.
