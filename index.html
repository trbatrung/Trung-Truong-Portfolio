02 — How I Choose Tools

Slop or salvation. Both are wrong.

Judgment,
not button-pushing

I don't start with a tool. I start with a question: what is this video for? Then I test the tools head to head, same brief, and log where each one breaks.

AI gets you to 80% fast. Knowing when 80% is the finish line is the difference between shipping and spinning.
